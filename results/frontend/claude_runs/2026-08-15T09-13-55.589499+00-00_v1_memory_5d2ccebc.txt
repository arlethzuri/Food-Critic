## What "cold holding" means in this dataset

There isn't a literal database column called "issue category" with a value "cold holding" — the schema stores each cited violation as a specific health‑code number (`violation_codes.code_text`) plus a free‑text description (`violations.violation_description`) and a `critical` flag. "Cold holding" is the informal grouping name for the set of citations dealing with keeping potentially‑hazardous ("TCS" – time/temperature‑control‑for‑safety) foods properly refrigerated.

Searching violation descriptions for "cold holding"/"cold plate" text turns up **85 violation records across 14 distinct codes**, split **32 critical / 53 non‑critical**. They cover things like:

- **Temperature failures (critical)** — e.g. code 4.3.59: "Shredded cheese is being held out of temperature control at 56°F on a counter cold holding unit"; code 4.4.51: a cold plate unable to hold food ≤41°F.
- **Knowledge/process failures (critical)** — code 4.2.2: staff unable to demonstrate knowledge of proper hot/cold holding temps; code 4.3.64: missing electronic time/temperature monitoring records for cook‑chill reduced‑oxygen‑packaged food; code 7.4.4(ii): inadequate power to run cold holding/handwashing systems.
- **Equipment condition (non‑critical)** — code 4.4.37 (by far the most common, 42 occurrences): cold holding units lacking an ambient thermometer; code 4.4.63: units leaking/not maintaining temperature; code 4.4.85/4.6.41: dirty/unclean cold holding equipment or floors beneath it.

So functionally, "cold holding" as an issue category refers to any violation tied to refrigeration equipment or practices meant to keep hazardous food at or below 41°F — ranging from a missing thermometer (minor) up to food actually found out of safe temperature (critical, direct foodborne‑illness risk).
