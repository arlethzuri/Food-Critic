Question: What's the difference between a critical and a non-critical violation, and how does each affect an inspection score?

--- Answer ---
A **critical violation** is a citation whose violation code is classified as critical in the SLCHD portal data; a **non-critical violation** is one classified as not critical. The classification is fixed at the code level—each code is consistently one or the other in this dataset.

On inspection scores:

- The data records a single **inspection score** for the entire visit, not a separate point deduction per individual violation type.
- Therefore, this dataset does **not** provide a documented formula such as “critical violations add X points and non-critical violations add Y points.” We can show association, but not infer a per-violation scoring rule.
- Inspections containing at least one cited **critical** violation had an average score of **21.6** across cited records, versus **15.9** for cited **non-critical** violations. Since higher inspection scores are described in the search tool as worse, critical citations are associated with higher scores in these records.
- There were **9,690** cited critical-violation rows (**10,744** total occurrences) and **22,339** non-critical rows (**25,862** occurrences).

The chart compares the average inspection score associated with each classification.
